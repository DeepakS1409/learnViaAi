Convolutional Neural Networks (CNN) — 13-Mark Structured Answer

A Convolutional Neural Network (CNN) is a specialized deep learning architecture optimized for processing spatial grid data like images and feature maps.

  • Convolution Layer: Applies learnable kernels to extract local spatial features (edges, textures).
  • Activation (ReLU): Introduces non-linearity: f(x) = max(0, x).
  • Pooling Layer: Downsamples feature maps (Max Pooling / Average Pooling) reducing spatial dimensions.
  • Fully Connected Layer: Aggregates high-level representations for final classification.
